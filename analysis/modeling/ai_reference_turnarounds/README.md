# ImageGen 建模多视角参考图库

> 生成方式：OpenAI 内置 ImageGen  
> 资产用途：Blender 建模前的补充视角与结构参考  
> 生成结果：10 张 1536×1024 参考板，58 张独立面板图  
> 一级依据：原视频帧与《三维建模资产需求与制作规范》  
> 二级依据：本目录内的 AI 生成参考图

## 1. 目录说明

| 分类 | 参考板 | 独立视角 | 用途 |

独立面板位于每个分类目录的 `panels/` 子目录。完整路径和尺寸见 [AI建模参考图索引.csv](AI建模参考图索引.csv)。

## 2. 建模使用原则

1. AI 生成图用于补足视频缺失视角，不是工程 CAD。
2. 轮廓、比例、节点层级和拆解规则与原视频冲突时，以原视频和主建模文档为准。
3. 地图只选一张顶视图描绘 SVG，不能分别按不同斜视图描边。
4. 地形先匹配大山脊、谷地、湖岸与风机点位，再制作细节。
5. 风机先按文档比例完成白模，再添加内部件和拆解层级。
6. 每次至少同时查看同一参考板的两个以上视角，避免被单张生成图误导。
7. B03 中的灰度高度图必须清理噪声、标记和湖区后才能用于 Displace。

## 3. 最终生成提示词集合

以下是本轮使用的提示词目标和强制不变量，后续需要重新生成时应继续沿用。

### A01 地图六视角

- 目标：同一自定义挤出区域地图的顶视、正视、左右侧视和两个轴测视图。
- 不变量：相同横向不规则外轮廓、12–14 个闭合分区、共边、统一厚度。
- 禁止：真实行政区、城市文字、风机图标、UI、光柱、粒子、环形装饰。

### A02 地图几何拆分

- 目标：顶面、共享边界网、侧壁、分区轻度爆炸、底面和装配状态。
- 不变量：沿用 A01 的轮廓、分区数量、边界和挤出厚度。
- 禁止：额外岛屿、孔洞、区域数量变化、玩具式厚倒角。

### B01 地形实体六视角

- 目标：同一风场地形的顶视、前后左右和前左高位斜视。
- 不变量：前景山脊、左前湖面、中央谷地、三处风机点位和远景山体。
- 风格：中性阴天、弱雾、自然绿地、灰绿色远山、白色低模风机。
- 禁止：新增湖泊、风机、建筑、重雾、奇幻山体和强透视。

### B02 地形线框六视角

- 目标：B01 同一地形的连续三角网格视图和局部拓扑特写。
- 拓扑：峰顶、陡坡和湖岸较密；平缓谷地较稀；避免极长窄三角形。
- 禁止：等高线、方格网、悬浮曲线、表面外装饰线。

### B03 地形高度与分层

- 目标：灰度高度图、彩色高程、灰模、主地形/远景/湖面/锚点分层。
- 不变量：沿用 B01 的地形边界、湖岸、山峰和三个锚点。
- 禁止：改造地形、新增地貌和不可读的高度噪声。

### C01 风机外观六视角

- 目标：同一三叶水平轴风机的前后左右、顶部和三分之四视图。
- 不变量：三片相同叶片相隔 120°；厚叶根、收窄叶尖、轮毂、胶囊机舱、偏航盘和锥形塔筒。
- 比例：叶片半径约 0.45H，轮毂直径约 0.065H，机舱长度约 0.15H。
- 禁止：额外叶片、透明、运动模糊、环境和 UI。

### C02 风机透明剖视

- 目标：透明外壳、侧视切开、顶部剖视、轮毂主轴连接和偏航接口特写。
- 不变量：红色法兰/主轴、蓝色轴承/联轴器/发电机、灰白底板、统一水平中心轴。
- 禁止：内部件漂浮、轴线错位、重复发电机、复杂管线和幻想机构。

### C03 风机爆炸装配

- 目标：装配、局部拆解、全拆侧视、顶视和两个斜视。
- 拆解组：Rotor、HubShell、FrontDrive、Bearing、GearGenerator、Bedplate、YawTowerTop。
- 方向：叶轮向主轴负 X，传动组向正 X，底板轻微上移，偏航和塔顶向下。
- 禁止：单片叶片脱离 Rotor、轴线不共线、出现无语义散件。

### C04 风机零件特写

- 目标：轮毂连接体、红色法兰主轴、蓝色轴承联轴器、发电机组、底板、偏航塔顶接口。
- 精度：适合实时 GLB 的中等细节、闭合网格、清晰倒角和装配接触面。
- 禁止：制造级内部齿轮、密集电缆、数百螺栓、镀铬材质。

### C05 风机线框拓扑

- 目标：整机前视/侧视、上部斜视、叶根、轮毂机舱和透明内部拓扑。
- 拓扑：叶根、轮毂插口、圆角和偏航盘加密；叶尖与直线塔筒逐步减面。
- 禁止：随机三角面、过密 CAD 网格、悬浮线、重复旋转残影。

## 4. 建议的 Blender 导入方式

- 将正交/侧视面板作为 Image Empty 放入对应正交视图。
- 将完整参考板放入 PureRef，用于同时检查多视角一致性。
- 不直接根据 AI 图估算真实米制尺寸；先使用主文档的归一化比例。
- 灰盒验收通过后，再使用透明、爆炸和拓扑板补充结构。
