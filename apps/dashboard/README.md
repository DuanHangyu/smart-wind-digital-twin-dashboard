# 智慧风电数字孪生可视化大屏

统一网站工程位于 `apps/dashboard`，采用 vinext、React 19 和 TypeScript。当前完成 W1：静态大屏壳层。

## W1 已完成

- 2560 × 1080 固定设计稿画布，并按浏览器窗口等比缩放、自动居中。
- 统一顶部品牌栏、环境信息、日期时间和装饰 HUD。
- P02 风场管理、P01 统计视图、P03 运维管理三页静态结构。
- 左侧指标、中央三维场景、右侧排行/趋势/告警三栏布局。
- 底部三页导航、键盘左右方向键切换和当前页面记忆。
- P01 使用 14 个自定义区域名称。
- 接入 A 自定义区域地图、B 艺术化风场地形、C 可拆解风机的静态渲染图作为场景占位。
- 为 W2 图表数据和 W3–W5 三维交互预留稳定页面与组件入口。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

访问 `http://localhost:3000/`。

## 验证

```bash
npm run lint
npm run build
npm test
```

## 当前边界

W1 只实现统一工程、视觉壳层、静态组件和页面切换。图表真实数据、GLB 模型加载、区域/风机拾取、弹窗、爆炸拆解和性能专项将在后续 W2–W6 迭代实现。
