# 智慧风电数字孪生可视化大屏

统一网站工程位于 `apps/dashboard`，采用 vinext、React 19 和 TypeScript。当前已完成 W1–W4，A 自定义区域地图和 B 艺术化风场地形均已进入真实三维交互。

## W1 已完成

- 2560 × 1080 固定设计稿画布，并按浏览器窗口等比缩放、自动居中。
- 统一顶部品牌栏、环境信息、日期时间和装饰 HUD。
- P02 风场管理、P01 统计视图、P03 运维管理三页静态结构。
- 左侧指标、中央三维场景、右侧排行/趋势/告警三栏布局。
- 底部三页导航、键盘左右方向键切换和当前页面记忆。
- P01 使用 14 个自定义区域名称。
- 接入 A 自定义区域地图、B 艺术化风场地形、C 可拆解风机的静态渲染图作为场景占位。
- 为 W2 图表数据和 W3–W5 三维交互预留稳定页面与组件入口。

## W2 已完成

- 10 份统一 fixture：项目元信息、统计摘要、14 区、趋势、告警、环境、10 台风机、单机详情、部件和资产清单。
- 数据适配器以 1 Hz 可复现地更新总发电量、月发电量、可利用率、环境、风速、功率和温度。
- KPI 数字使用 620 ms ease-out 补间，避免实时数据跳变和布局抖动。
- 双柱、环图、排行、折线、告警、环境、设备表和实时参数均为数据驱动的可复用组件。
- 排行和设备表循环滚动，鼠标悬停时暂停；双柱和折线支持数据 Tooltip。
- P01 风机/地标/动画开关、900 ms 区域轮播；P02 水面/投影状态；P03 四模式互斥和独立动画开关。
- 页面与控制状态保存到浏览器本地；组件具备空数据展示能力。

## W3 已完成

- 接入 A v2 的 1.2 MB KTX2 网页低模，模型包含 14 个 `PART__REGION_*`、14 个 `HOTSPOT__REGION_*` 和 14 个发光轮廓节点。
- Three.js 场景自动居中、缩放、照明、雾化、轨道旋转、触控缩放和视角复位。
- 鼠标或触控选择区域，区域平滑抬升 0.28 单位并增强实体与轮廓自发光。
- Hover 区域抬升 0.10 单位，暂停自动轮播与场景旋转；离开后恢复。
- 14 个 DOM 标签由 GLB 热点节点实时投影，标签与模型选择双向联动。
- 程序化增加 4 个风机点位；风机、地标和动画按钮直接控制 Three.js/DOM 场景层。
- 提供加载进度、WebGL 检测、静态图降级和完整资源释放。

## W4 已完成

- 接入 B V5 的 3.05 MB KTX2 网页低模，包含 43,688 三角面、6 个 `PART__*`、4 个 `HOTSPOT__*` 和 3 个 `ROTOR__*`。
- 模型风机 01/02/03 映射为业务设备主风机 A/B/D，模型点击、热点标签、锚点详情卡和设备状态表双向联动。
- 风机详情卡显示 1 Hz 更新的功率、风速和运行状态；点击空白或关闭按钮清理选择。
- 三台风机读取 GLB 中 Blender 局部 Y 轴与 RPM 元数据，并在浏览器中将该轴正确换算为 glTF 局部 -Z 后持续旋转；离线设备停止，待机与异常状态通过标签颜色区分但不破坏持续旋转要求。
- 水面按钮控制真实 `PART__LAKE` 显隐；投影按钮控制地形三角线框，保持同一相机和选中状态。
- OrbitControls 支持旋转缩放，用户操作时暂停巡航，5 秒后自动恢复；提供视角复位。
- 4 个 DOM 标签来自 GLB 热点实时投影，包含三台风机和山地湖泊。
- 保留加载百分比、WebGL 检测、静态图降级、触控适配和完整 GPU 资源释放。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

访问 `http://localhost:3000/`。

## 验证

```bash
npm run lint
npm run build
npm test
```

## 当前边界

当前使用稳定模拟数据，不连接真实 SCADA 接口。A 区域地图和 B 风场已完成真实 GLB 接入；C 单机、爆炸拆解和性能专项将在后续 W5–W6 迭代实现。
